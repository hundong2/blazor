# C# 최신 문법 및 Blazor & MAUI 실무 커리큘럼

본 학습 자료는 최신 C# 문법을 익히고, 이를 바탕으로 Blazor와 .NET MAUI를 활용하여 실무에서 바로 적용 가능한 웹/모바일/데스크톱 크로스 플랫폼 애플리케이션을 개발하는 것을 목표로 합니다.

## 📌 커리큘럼 개요

단순한 이론 학습이 아닌, 실무에서 자주 마주치는 패턴과 문제 해결에 초점을 맞추어 단계별로 구성되어 있습니다. 각 단계(Step) 폴더에는 개념 설명, 실습 예제(코드), 그리고 실무 적용 팁이 포함되어 있습니다.

### [Step 1: Modern C# 실무 필수 문법](./Step1_ModernCSharp/)
최신 C# (C# 9.0 ~ 12.0)의 기능 중 Blazor 및 MAUI 개발에서 생산성을 극대화하고 코드를 간결하게 만들어주는 핵심 문법을 학습합니다.
* **주요 내용:** Records(불변 데이터 모델링), Pattern Matching(고급 제어 흐름), Primary Constructors(간결한 의존성 주입), Nullable Reference Types(안전한 코드 작성).
* **실무 목표:** DTO 및 뷰모델 작성을 간소화하고, 비즈니스 로직의 가독성을 높입니다.

### [Step 2: Blazor 실전 가이드](./Step2_Blazor/)
Blazor 프레임워크를 이용한 최신 웹 UI 개발을 다룹니다.
* **주요 내용:** 컴포넌트 생명주기와 재사용, 상태 관리 패턴, JavaScript Interop(JS와의 연동), 폼(Form) 검증 및 데이터 바인딩.
* **실무 목표:** 재사용 가능한 UI 컴포넌트 라이브러리를 구축하고, 복잡한 사용자 입력을 처리하는 화면을 구성합니다.

### [Step 3: .NET MAUI 크로스 플랫폼 개발](./Step3_MAUI/)
하나의 코드로 iOS, Android, Windows, macOS 앱을 만드는 .NET MAUI를 다룹니다.
* **주요 내용:** XAML 기초 및 데이터 바인딩, CommunityToolkit.Mvvm을 활용한 MVVM 패턴, App Shell 네비게이션, 플랫폼 고유 API 접근.
* **실무 목표:** MVVM 아키텍처 기반의 모바일 앱을 설계하고, 효율적인 화면 전환 및 네이티브 기능 연동을 구현합니다.

### [Step 4: 실전 프로젝트 & Blazor Hybrid](./Step4_PracticalProjects/)
앞서 배운 지식을 통합하여, 웹 기술로 네이티브 앱을 만드는 Blazor Hybrid와 실무 아키텍처를 학습합니다.
* **주요 내용:** .NET MAUI Blazor App 구성, 웹/모바일 코드 공유 전략, 클린 아키텍처 기반의 프로젝트 구조.
* **실무 목표:** 웹(Blazor)과 모바일/데스크톱(MAUI) 간에 UI와 비즈니스 로직을 최대한 공유하는 효율적인 멀티 플랫폼 프로젝트를 구축합니다.

4. 코드 리뷰나 페어 프로그래밍을 하듯 코드를 읽고, 스스로 주석을 달아보는 것을 권장합니다.
